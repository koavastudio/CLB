Litter Buddy - Interactive Cat Litter Box Stream Widget
=======================================================

A cute, funny litter box for your stream. When a viewer supports you, a cartoon
cat (every viewer keeps their own cat coat) hops into the litter box, digs, squats and
leaves a little pastel swirl, kicks sand over it and hops out, while a receipt pops
up with the viewer's name, the event, their message and a TOTAL. The swirls pile up
in the box and the cream slot on the box is your goal bar. When the goal is reached
a giant scoop comes and cleans the box, with confetti.
Works with StreamElements (Twitch & YouTube). No coding - copy & paste.

START HERE
Open "1 - START HERE - Setup Guide.html" for step-by-step install with copy buttons.

LIVE PREVIEW
Open "2 - Live Preview.html" in your browser. Pick the cat colors, recolor the box,
test every event, then press the copy buttons (HTML / CSS / JS / Fields / Data).
The Data button carries your settings (paste it into the DATA tab).

INSTALL
1. StreamElements -> Streaming Tools -> My Overlays -> open/create an overlay.
2. + Add Widget -> Static / Custom -> Custom Widget.
3. Open the editor and paste each part into its matching tab:
   - Widget Code/1. HTML.txt   -> HTML tab
   - Widget Code/2. CSS.txt    -> CSS tab
   - Widget Code/3. JS.txt     -> JS tab   (artwork embedded - nothing to upload)
   - Widget Code/4. Fields.txt -> Fields tab
   - Your settings: in the Live Preview press "Data" and paste it into the DATA tab
     (select everything there first and replace it). StreamElements keeps the settings
     in DATA, so changes copied only into Fields don't show up.
     Paste Data FIRST, then upload your own background / sounds in the settings panel:
     pasting Data again later removes those uploads.
4. Save. Resize the widget box to cover the overlay; the scene keeps its proportions.
5. Press "Send a test cat" in the settings panel to see it run.
6. Add the overlay URL to OBS / Streamlabs as a Browser Source.

HIDE WHEN IDLE (new in this version)
Settings -> General -> "Hide the widget while nothing is happening": fade out, slide
down or shrink away after the last cat visit. It pops back in for every new cat visit, and
optionally whenever the goal changes.
It never hides inside the overlay editor.

UPDATING FROM AN OLDER VERSION
Paste the new CSS, JS and Fields parts over the old ones and save. Leave the DATA
tab alone: your settings and goal progress are kept.

WHAT SENDS A CAT
Tips + Super Chats (minimum amount), bits (minimum bits), subs + gift subs +
YouTube members, follows, raids, a chat command (default !litter) with cooldown
and permission, and Twitch channel point rewards (by reward name). Each one can be
turned off. Up to 3 cats (1-4, your choice) use the box at the same time, each in its
own spot; more than that wait in line next to the box (or a "+N" bubble shows how many
are waiting). While a receipt is open, every new cat adds its own line to it
("FOR: 3 VISITORS", one TOTAL = what went into the goal), so the screen never fills up.

WHERE THE CATS COME FROM
"Cats come from": the bottom of the screen (default - the cat leaps up into the box,
works in any corner), the nearest screen side, or always left / right. Entrances are
measured from the real screen edge, so the box can sit in any corner.
Little characters (can be turned off): follows send a kitten, subs wear a crown,
big tips strut in with a swagger, raids bring a party of cats (as many as fit in the
box: "Cats in the box at once", 3 by default). While it is quiet
a cat peeks over the rim now and then (can be turned off).

CAT COATS
Natural coats by default: black, blue-grey, white, cream, ginger, chocolate, grey /
ginger / brown tabby, calico and tuxedo. The coat comes from the viewer's name, so a
regular always arrives as the same cat. Tick off the coats you don't want. Or switch to
fantasy colors by event type, random fantasy colors, or the original grey cat.
Every event type has its own name-tag color (tip, bits, sub, follow, raid, channel
points, chat), so you can still tell what sent the cat.

SWIRLS + GOAL
Every visit leaves a pastel swirl: gold for big tips, rainbow for subs and raids,
caramel or pink otherwise. The box holds up to 12; when it is full a scoop can clean it.
Tips, bits and subs feed the goal (follows, raids, chat and channel points optional).
The bar in the cream slot shows the title and amount (money, numbers or percent).
Reaching the goal brings the giant scoop + confetti, then the goal starts again.
Progress and the swirls are saved across overlay refreshes. Change the "Goal reset key"
to start over.

BOX COLOR
Hue, Saturation and Lightness sliders recolor the box to any color. Hue 0 +
Saturation 100 is the original mint. The cream rim, slot, feet and paw prints stay
cream. The goal bar fill and text colors are separate.

BACKGROUND
Transparent by default, or the built-in cozy peach room, or your own image.

SOUND
Built-in meow, sand digging, plop, scoop and receipt-printer sounds, or upload your own.
