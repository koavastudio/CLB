Install Litter Buddy

✨ Fully automatic: once installed, a cat visits the litter box for every tip, bits, sub, follow, raid, chat command and channel point reward on its own. You don't have to press anything during your stream.

How it works

  1. Click Install Litter Buddy and sign in with StreamElements.
  2. The Litter Buddy overlay is added to your StreamElements account (Streaming Tools ▸ My Overlays).
  3. Open that overlay and click Copy URL at the top (the overlay link, not the editor page's address).
  4. In OBS or Streamlabs add a Browser Source, paste the URL and set the size to 1920 × 1080. Put it above your game and camera.

To try it: open the widget's settings and click Send a test cat.

🛠️ Not showing in OBS? Check that the Browser Source is 1920 × 1080, and that "Hide the widget while nothing is happening" (Settings ▸ General) is set to Never if you want the box visible all the time. For the manual (copy & paste) install, open 1 - START HERE - Setup Guide.html from your download.
