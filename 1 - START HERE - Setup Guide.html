1 Create a Custom Widget

  1. In StreamElements go to Streaming Tools ▸ My Overlays.
  2. Open an overlay, or click New Overlay (1920 × 1080).
  3. Click + Add Widget → Static / Custom → Custom Widget.
  4. Open the widget's code editor. You'll see the HTML · CSS · JS · FIELDS tabs.

5 Paste the Fields

Open the FIELDS tab, delete everything in it, then paste. This creates the settings panel. Styled it in the Live Preview? Click Save, open the DATA tab, replace everything there with the preview's Data copy and save again (StreamElements keeps the settings in DATA). Order matters: paste Data first, then upload your own background / sounds in the settings panel. Pasting Data again later removes those uploads.

FIELDS→ Fields tab

6 Save, size & add to OBS

  1. Click Done, then Save the overlay.
  2. Stretch the widget box to cover the whole overlay. The scene keeps its shape and sits bottom-center; move it with Horizontal / Vertical align and Overall size.
  3. Copy the overlay URL and add it to OBS or Streamlabs as a Browser Source at 1920 × 1080.
🔊 In OBS, tick Control audio via OBS on the Browser Source so the meows, sand digging, plops, chime and receipt sounds go into your stream audio.

7 Test it

  • Open the widget settings and go to the Test group. Pick a Test cat event type (each event has its own cat color) and click Send a test cat (it runs at demo speed).
  • Click Add test amount to the goal to fill the bar on the box, Play the scoop celebration to see the giant scoop clean the box, and Reset goal + empty the box to start over.
  • Or use the overlay's Emulate button to send a fake tip, cheer, sub, follow or raid. Several at once? Up to 3 cats use the box together; the rest wait in line next to the box.
  • In chat, type !litter (or your own command) to try the chat trigger.

★ Twitch channel points (optional)

  1. On Twitch, open Creator Dashboard ▸ Viewer Rewards ▸ Channel Points and add a custom reward, for example Litter Visit.
  2. Optionally turn on Require Viewer to Enter Text so the message shows on the receipt.
  3. In the widget's Triggers group, type the exact reward name into Channel point reward name. Leave it empty to accept any reward.
💡 Channel point cats have their own color (Cat Colors group) and the receipt shows the points cost.

? Troubleshooting & FAQ

Nothing happens when I tip or emulate an event.

Check that the event is turned on in Triggers and that the amount reaches Minimum tip or Minimum bits. Make sure the widget box covers the overlay and isn't hidden behind another widget.

My Live Preview settings don't show up in StreamElements.

StreamElements keeps settings in the DATA tab. In the Live Preview press Data, open the widget's DATA tab, replace everything there with it and save.

Every cat leaves the same swirl.

Look at Always leave swirl # in the Test group: 0 means by event (gold for big tips, rainbow for subs and raids, caramel or pink otherwise).

The box shows swirls in my screenshots that aren't real.

Set Show this many swirls in the box and Show this goal amount (Test group) back to -1.

The goal or the swirls are gone after a refresh.

The goal and the swirls in the box are saved in the StreamElements store (and this browser). Press Check saved data in the Test group: it tells you whether StreamElements answered and how many saves it holds. If it never answers, reload the overlay once; writes stay off until the store has been read, on purpose.

Channel point redemptions don't send a cat.

The reward name must match exactly (capital letters don't matter). Empty the Channel point reward name field to accept every reward, then test again. Channel points are a Twitch feature.

My box sits in a corner and the cats appear in the middle of the screen.

They shouldn't: entrances are measured from the real screen edge. Make sure the widget box covers the whole overlay (1920 × 1080). With the box in a corner, Cats come from = The bottom of the screen (default) or The nearest screen side works best.

Too many cats at once?

Turn off the events you don't want in Triggers (for example follows during a follow train), lower Max cats waiting in line or raise Animation speed.

How do I reset the goal?

Click Reset goal + empty the box or change the Goal reset key.

Gift subs: whose cat is it?

The gifter's. A community gift of several subs sends one cat and counts every gifted sub toward the goal.
